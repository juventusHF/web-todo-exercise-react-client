# web-todo-exercise-react-demo

Simple react frontend generated with vite.  
Talks to https://github.com/juventusHF/web-todo-exercise-server

Demos CRUD operations for Todos.

run `npm install` and then `npm run dev` to start the dev server locally.  
Access the frontend in the browser on http://localhost:5173

The exercises are described in [EXERCISES.md](EXERCISES.md).
